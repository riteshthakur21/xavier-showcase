01 — Core capabilities

Everything a college
alumni network needs.

Admin Verification

Multi-step approval workflow. Every registration goes through admin review before activation. Automated email alerts via Brevo API.

JWT Auth RBAC

Real-Time Encrypted Chat

Socket.io powered messaging gated behind accepted connections. End-to-end AES-256-GCM encryption — database-level privacy.

Socket.io AES-256

LinkedIn-Style Connections

Full bidirectional connection system. Send, accept, reject requests. Notifications on every action via in-app bell and Socket.io.

Prisma ORM PostgreSQL

Alumni Job Board

Alumni post exclusive job openings. Students browse and apply directly within the network. No third-party middlemen.

Next.js 14 Express API

Events & Stories

Create and manage alumni events with audience targeting by batch year and department. Alumni Stories with approval workflow.

Cloudinary Neon DB

Real-Time Notifications

Full notification system wired to connection requests, story approvals, and more. Live delivery via Socket.io with badge counts.

Brevo Email Google OAuth
02 — Architecture

A modern,
battle-tested stack.

Each technology was chosen deliberately — for type-safety, real-time capability, and production-readiness on free-tier infrastructure.

FE
Next.js 14 (App Router) + Tailwind CSS
Server components, inline SVG icons only, no shadcn or framer-motion
BE
Node.js + Express.js + Prisma v6
REST API, JWT auth, Socket.io, connect-pg-simple session store
DB
PostgreSQL on Neon + Prisma ORM
Serverless Postgres, schema managed via npx prisma db push
IO
Socket.io + Cloudinary + Brevo
Real-time events, media storage, transactional emails
CD
Vercel (frontend) + Render (backend)
cron-job.org pings /ping every 5 min to keep Render alive
Full dependency tree
Next.js 14 React 18 Tailwind CSS Node.js Express.js Prisma v6 PostgreSQL Neon DB Socket.io JWT Google OAuth bcrypt AES-256-GCM Cloudinary Brevo API axios js-cookie Vercel Render cron-job.org connect-pg-simple
Security highlights
  • → AES-256-GCM message encryption at rest
  • → RBAC: Admin / Alumni / Student roles
  • → Email OTP verification for multi-step registration
  • → Admin approval gating before any account activation
  • → bcrypt password hashing + JWT expiry
03 — Developer setup

Up and running
in minutes.

bash — xavier-alumni-connect
# Clone the repository
➜ ~ git clone https://github.com/riteshthakur21/xavier-alumni-connect.git
➜ ~ cd xavier-alumni-connect

# Backend setup
➜ backend npm install && npx prisma db push
➜ backend npm run dev

# Frontend (new terminal)
➜ frontend npm install && npm run dev

✓ App running at http://localhost:3000 ▊
⚠ Gotcha #1
After updating BREVO_API_KEY in .env, nodemon won't auto-restart — manually Ctrl+C and restart.
⚠ Gotcha #2
Never delete users directly from DB — use the admin dashboard. It clears linked tables (jobs, events) before deletion.
⚠ Gotcha #3
MESSAGE_SECRET_KEY must be exactly 64 hex chars. Server crashes intentionally on misconfiguration.
⚠ Gotcha #4
Render env vars must be added to the service directly, not an Environment Group, for them to take effect.
